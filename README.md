# FEVERFLOW

Smart Quarantine & Treatment Management System — React + Vite + Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this project/repository into Vercel. Vercel should detect Vite automatically.
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

This is a demonstration prototype. Demo sign-in and browser localStorage are not production authentication or secure medical-record storage. All seeded patients are fictional.
